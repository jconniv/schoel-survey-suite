Schoel Survey Suite Full Download

Included in this package

1. Bearing Deed Plotter
   The current working EXE is bundled under embedded_deed_plotter and launched from the suite.

2. Bearing Legal Writer
   Preserved from the uploaded legal_writer source.

3. Interior Angle Legal Writer
   Preserved from the uploaded Birmingham legal writer source.

4. Interior Angle Deed Plotter
   Included from the uploaded interior angle plotter source with a small wrapper app.py so the suite can launch it.

5. Future tool placeholders
   Call Finder / Error Checker
   Closure Report Tool
   Curve Table Generator
   DXF Polyline Import Tool
   Bearing and Interior Angle Converter
   Coordinate Converter
   Survey Text Exporter
   Exhibit Note Builder
   Map Check Assistant
   AI Helper Panel

Notes

- The legal writer wording was not rewritten.
- The bearing deed plotter is currently integrated as its working EXE.
- The suite icon is set to the Schoel logo .ico file.
- This package was assembled as a Windows ready source/build bundle.
- The single Windows EXE still needs to be built on Windows with PyInstaller using build_windows_exe.bat.

Typical folder launch during development

python suite.py

Windows build

build_windows_exe.bat
